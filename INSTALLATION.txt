TRANSPORTER-SPIEL - KURZE INSTALLATION UND START

Voraussetzung ist die Installation von python

Windows:
1. cd Pfad\zum\Ordner
2. py -m pip install pygame
3. py main.py

Linux:
1. cd /pfad/zum/ordner
2. python3 -m pip install pygame
3. python3 main.py

Falls der Startbefehl nicht funktioniert, pruefe zuerst, ob Python installiert ist.
